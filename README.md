# A Little Blue for Manju 💙

A cozy, mobile-first Next.js website for a best friend. Features gentle messages, interactive letters, bubbles, compliments and a tiny star game.

## Setup

Requires Node.js 20.9+.

```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Deploy
Import this repository at https://vercel.com/new, keep the Next.js defaults and deploy. No environment variables are needed.

The website is intended to be a low-pressure supportive gift; it never asks Manju to explain why she is sad. The playlist section is a visual mood board, not playable audio.
